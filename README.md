# HEAL English

เว็บแอปฝึกและช่วยสื่อสารภาษาในงานบริการผู้ป่วย

## อัปเดตล่าสุด
- เลือกหรือเปลี่ยนห้องตรวจแล้วส่ง event ไปยัง Google Sheets แยกตามห้อง/วันที่ โดยไม่แสดงสถิติในหน้าเว็บ
- แยก Google Translate สำหรับพิมพ์/พูดทีละข้อความ ออกจาก AI Translator สำหรับล่ามเสียงสองทางแบบ Real-time พร้อม hero และ AI orb
- ประโยคและการ์ดฝึกแสดงความหมายภาษาไทยไว้ก่อนคำแปล; AI Role Play Quiz ใช้ฝึกภาษาอังกฤษโดยไม่มีตัวเลือก Burmese
- AI Translator ตรวจอักษรไทย/English/中文/မြန်မာหลังรู้จำ และเลือกได้ว่าจะให้บุคลากรพูดไทยหรือผู้ป่วยพูดภาษาที่เลือกก่อน
- ปุ่มเสียง Burmese ใช้ Google TTS โดยตรงทุกส่วน และมีการแจ้งเตือนเมื่อเบราว์เซอร์บล็อกเสียง
- เพิ่ม Burmese ในคลังประโยค วลีด่วน การฟัง/พูด/ฝึกพูด การพิมพ์ และหน้าล่าม; AI Role Play Quiz คงไว้สำหรับฝึกภาษาอังกฤษ
- ส่งบันทึกแบบไม่มีข้อมูลผู้ป่วยไปยัง Google Sheets ผ่าน Google Apps Script
